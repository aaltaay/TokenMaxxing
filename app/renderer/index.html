Spend the cheapest thing that will actually work

Reference · nothing read

Most quota goes to overkill: a heavyweight model grinding at maximum effort on something a default would have finished. Two dials decide the bill, and they move independently — which model reasons, and how hard it works on this turn.

Dial one · model

Who is reasoning: a generalist, an expert, or a specialist. Changes what the answer is capable of being.

Dial two · effort

How hard that one model works before answering. Changes the token spend far more than it changes the model.

They compose. A top-tier model at low effort is a real and useful combination — five minutes with the expert, who still brings the pattern recognition even when it is not spending deep tokens per step.

Claude

Claude Code · claude.ai
Haiku 4.5
The small, fast one. Narrow mechanical work where the answer is already obvious and only the typing is slow.
Reach for it when you are renaming things, reformatting, extracting a value, or handing a subagent grunt work you will check yourself.
Sonnet 5 Default
Everyday coding, writing, research, agentic tool use. This is where you live by default.
Step away from it only when the task clearly outgrows it — not because a task merely sounds important.
Opus 5
The expert. Cross-cutting refactors, hard debugging, architecture calls — problems where a wrong answer costs more than the tokens.
Reach for it when being wrong is expensive, the run is long and autonomous with no check-ins, or the problem is genuinely novel rather than a variation on something already seen.
Fable 5.1
The specialist. You describe the result, not the path, and it works out the steps you would otherwise have had to specify.
Reach for it when the outcome matters more than the procedure: root-cause investigations, ambiguous outages, work you would normally break into pieces because no single sitting covers it.

Effort

The dial that actually moves the bill

Effort is set per turn and applies across the models that support it. Moving it one notch changes spend more than most model swaps do.

low Most efficient, and a real reduction in capability. Short, scoped, latency-sensitive work — not intelligence-sensitive. Good for subagents.
medium Moderate token savings, balanced. Cost-sensitive work that can afford to trade away some intelligence. The average-workflow drop-in.
high The default almost everywhere. Complex reasoning, difficult coding, agentic tasks. This one is simply “normal” — not a treat.
xhigh Extended capability, higher spend. The hardest coding and agentic tasks, and long-running work — half an hour and up, on million-token budgets.
max No constraints on token spending. Frontier problems only. Everywhere else it buys diminishing returns and risks overthinking a solved question.

ultracode is a different kind of switch, and Claude Code only: xhigh effort plus standing permission to fan work out across parallel subagents. It is not a “how hard should it think” dial, it is a “should this fan out” dial — worth it for large tasks that split into independent chunks, wasteful for anything that does not.

Codex

OpenAI · CLI and IDE
GPT-6 Astra
The model Sessions prices for you. Published Standard API rates are $10 per million input tokens, $1 cached, $50 output.
Output is the expensive half — fifty times cached input. A turn that reasons briefly and writes a long file costs more than one that reads widely and answers in a paragraph.
Cached input
Re-sent context the provider already holds is billed at a tenth of fresh input.
This rewards staying put. Continuing one long chat keeps the prefix cached; starting a fresh chat on the same task re-reads everything at full price.
Past 272k tokens
A hard cost cliff: beyond 272,000 input tokens, input bills at double and output at one and a half times.
Watch the context figure in Sessions. Compacting or splitting the task before the cliff is the single largest saving available on this provider.
Reasoning effort
Codex exposes the same kind of dial as Claude, and it behaves the same way.
Leave it at the default for ordinary work and raise it deliberately, for one hard task, rather than setting it high and forgetting.

Cursor

Editor · metered by request
Tab
Inline completion as you type. The cheapest useful thing in the editor by a wide margin.
Most edits never needed an agent. If you already know what the line should say, typing it with Tab costs a rounding error of what asking costs.
Ask
Answers a question about the code without editing anything.
Use it when you want to understand, not change. An agent run that reads, plans, edits and re-reads costs many times a plain answer.
Agent
Reads, edits and iterates across files on its own. Every loop is another metered request.
Scope it before you run it. Pointing at the two files that matter costs a fraction of letting it search the repository to find them.
Auto
Lets Cursor route the request instead of pinning a frontier model to every message.
A reasonable default when you are not sure the task needs the top model. Pin one deliberately when it does.

Everything else

Copilot · Gemini · the rest
Find the metered unit
Every assistant bills something different: tokens, requests, premium requests, or a seat with a fair-use ceiling.
Learn which one you pay in first. On a per-request plan, one long careful message beats five short ones; on a per-token plan the reverse is often true.
Premium vs included
Most tools keep a cheap or included tier alongside the models that draw down a premium allowance.
The included tier is usually enough for completion, explanation and small edits. Spend the premium allowance on the work that is actually hard.
Free tiers are real
Several vendors give a daily allowance that resets whether or not you used it.
Spend the free one first. Routine work done on an allowance that expires anyway is work your paid quota never sees.

Habits that cost nothing

Start low, escalate on evidence
Opening every task on the biggest model at the highest effort is how a quota disappears. Start at the default and move up when the default visibly struggles — not when the task merely sounds hard.
Narrow the context before you ask
Naming the files costs you ten seconds and saves a search across the whole repository. Context is the input bill, and input is charged on every turn of a long conversation, not just the first.
One long chat beats five fresh ones
Re-sent context is discounted; re-explaining a task from scratch is not. Stay in the session while the topic holds, and open a new one when the topic genuinely changes rather than out of tidiness.
Spend against the reset, not the day
Quota that expires unused is quota wasted. Limits & resets shows when each window turns over; heavy work parked just before a reset gets a full allowance instead of the end of one.
